### Optimal Sort Heuristic

This honors thesis project analyzes current sorting methods to identify their best cases 
and implements an optimal sorting algorithm for various data types and input lengths. 
This requires evaluating the data type, size, and sorted state of the input values, 
and selecting the algorithm that sorts the input in the fastest manner. 
It explores three different datatypes including Integers, Floats, and Strings. 
The main idea is to develop a heuristic to select the optimal sorting algorithm 
for a given input, based on its data type and array length.
